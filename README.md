 Mukula David - Modern Portfolio

A modern, responsive portfolio website showcasing my skills as an Electrical & Software Engineer. Built with clean HTML, CSS, and vanilla JavaScript.

 Features

- Modern Design: Clean, professional layout with modern CSS and smooth animations
- Responsive: Fully responsive design that works on all devices
- Interactive: Smooth scrolling navigation, hover effects, and scroll-triggered animations
- Professional Sections:
  - About with key statistics
  - Professional Experience timeline
  - Technical Skills organized by category
  - Education background
  - Featured Projects with technology tags
  - Contact information

 Technologies Used

- HTML5: Semantic markup and accessibility
- CSS3: Modern styling with CSS Grid, Flexbox, and custom properties
- JavaScript: Vanilla JS for interactivity and animations
- Google Fonts: Inter font family for modern typography
- Font Awesome: Icons for visual enhancement

  Sections

1. Header: Sticky navigation with smooth scrolling
2. About: Personal introduction with key statistics
3. Experience: Professional background timeline
4. Skills: Technical skills organized by category
5. Education: Academic background timeline
6. Projects: Featured work with live/demo links
7. Contact: Multiple ways to get in touch
8. Footer: Quick navigation links

Design Features

- Light theme with professional color scheme
- Smooth animations and transitions
- Card-based layouts for better content organization
- Interactive hover effects
- Modern typography and spacing
- Mobile-first responsive design

 Getting Started

1. Clone the repository
2. Open `index.html` in your browser
3. Customize the content in `index.html` and `style.css`
